# Tableau de bord & navigation

Après connexion, vous accédez à la liste des **Coffres-forts de l’étude** (ou du
cabinet). C’est votre point de départ pour gérer l’ensemble de vos dossiers clients.

## Vues et filtres

La liste des coffres-forts peut être filtrée selon plusieurs vues :

| Vue | Contenu |
| --- | --- |
| **Tous** | Tous les coffres-forts de l’organisation. |
| **Récents** | Les coffres-forts ouverts récemment. |
| **Favoris** | Les coffres-forts marqués comme favoris. |
| **Archivés** | Les coffres-forts archivés. |
| **Partagés avec moi** | Les coffres-forts partagés par un confrère. |

## Naviguer dans un coffre-fort

En ouvrant un coffre-fort, vous accédez à son explorateur : les **espaces**, les
**dossiers**, les **fichiers**, et les actions de dépôt et de demande de documents.

## Suivi de l’activité

Un **tableau de bord analytique** (réservé à l’administration) présente la création
de coffres-forts par type et par mois, pour suivre l’activité de votre organisation.
