# Le plan Premium

L’abonnement Premium vous donne accès à votre **coffre-fort personnel** et à des
options de sécurité avancées.

## Ce qu’inclut le Premium

- **Coffre-fort personnel** privé pour vos documents confidentiels ;
- Stockage étendu et organisation libre de vos fichiers ;
- Désignation d’une **personne de confiance** pour un accès d’urgence ;
- **Vérification d’identité** pour vos documents sensibles.

## Offre gratuite vs Premium

| | Offre découverte | Premium |
| --- | --- | --- |
| Documents | Limité (offre d’essai) | Étendu |
| Coffre-fort personnel | — | ✅ |
| Personne de confiance | — | ✅ |
| Vérification d’identité | — | ✅ |

## Tarif

L’abonnement Premium est proposé à **84 € par an**, avec paiement sécurisé.
