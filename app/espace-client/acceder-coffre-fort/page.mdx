# Accéder à votre coffre-fort

Après connexion, vous arrivez directement sur la liste de vos coffres-forts
(**Mes coffres-forts**).

## Filtrer vos coffres-forts

La liste peut être filtrée selon plusieurs vues :

| Vue | Contenu |
| --- | --- |
| **Tous** | L’ensemble de vos coffres-forts. |
| **Récents** | Les coffres-forts consultés récemment. |
| **Favoris** | Les coffres-forts que vous avez marqués d’une étoile. |
| **Archivés** | Les coffres-forts archivés (masqués mais conservés). |
| **Partagés avec moi** | Les coffres-forts qu’un tiers a partagés avec vous. |

## Ouvrir un coffre-fort

Cliquez sur un coffre-fort pour ouvrir son **explorateur de fichiers**. Vous y voyez :

- les **espaces** (catégories de documents) du coffre-fort ;
- les **dossiers** et **fichiers** qu’ils contiennent ;
- la zone de **téléversement** pour ajouter des documents.

<Callout type="info">
  Marquez vos coffres-forts importants comme **favoris** pour les retrouver
  rapidement depuis la vue « Favoris ».
</Callout>

## Coffre-fort partagé avec vous

Lorsqu’un professionnel ou un proche partage un coffre-fort avec vous, il apparaît
dans la vue **Partagés avec moi**. Vous pouvez le consulter selon les droits qui
vous ont été accordés.
